# Play listing — ep

**Title (30):** ep — a calculator you write

**Short description (80):**
Write calculations with units. They check themselves and turn into forms you can send.

**Full description (4000):**

ep is a notepad calculator. You write what you're working out, line by line, and every
line shows its answer beside it. Numbers carry their units: 3 km / 4 min is 45 km/h,
150 lb -> kg is 68.04 kg, and metres plus seconds is an error before anything is
computed, not a wrong number afterwards.

Touch a number and everything below it recomputes. Tag a line as an input, tag another
as an output, and "Make form" turns the sheet into a single file anyone can open, change
the inputs on, and read the results from. No account, no install on their side, no
internet needed: the form is one HTML file that works in any browser, now and years from
now.

What you get:
• Units in the maths, with conversion by writing -> and the unit you want
• A dimension check that catches mistakes as you type
• A keyboard row built for thumbs: operators, the arrow, and a units sheet
• Inputs as tappable chips, results large and readable
• Forms you can share through any app, or save as a file
• Uncertain values (normal, uniform, lognormal) that carry through the arithmetic
• Plots, datasets from CSV, and a growing function library
• Works offline. Your sheets stay on your phone.

ep's language is a calculator-shaped subset of Numbat (David Peter, MIT). ep is free
software from the Geoscientific Chaos Union, gentropic.org.
